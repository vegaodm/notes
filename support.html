Notes & Ideas Support

Help for managing notes, tags, Markdown Preview, Trash, and import and export features locally.

App version: 1.0 (Build 1) Minimum system: iOS 17.0 Page updated: September 26, 2026
Markdown Preview

Tap Preview at the top right of the Title section to open a full-screen preview. Use the centered top controls, pinch to enlarge content, and double-tap to zoom or reset.

Search and tags

Scroll to the very bottom of the list and pause for about one second to bring up the floating search bar. Tap a tag to filter, or press and hold a tag to clear the filter, rename it, or delete it. Each tag keeps a stable color in the list, in the filter row, and in the editor.

Note list

Each note is one compact row: title, pinned marker, up to three tags, a numeric date, and a two-line body preview. Swipe a row to pin it or move it to Trash.

Trash

Deleting a regular note first moves it to Trash. Restore it from Trash, or use Delete Forever to remove it permanently.

Import and export

Full data uses JSONL files, and single notes use JSON files. The iOS file picker handles file access.

Using Full-Screen Markdown Preview

  1. Open a note and tap the blue Preview button in the Title section header. The button is disabled while the note has no content.
  2. The app opens a full-screen Markdown preview over the editor. Preview is at the top left and Done is at the top right.
  3. Use the centered -, +, or reset controls. You can also pinch the content or double-tap it.
  4. Tap Done to return to the editor. After rotating the device, the preview is laid out again for the new screen width.

Preview supports headings, paragraphs, regular lists, task lists, block quotes, code blocks, dividers, tables, and common inline Markdown formatting. Tables honor column alignment written as :---, :---:, or ---:. Text wrapped in ~~double tildes~~ is rendered with a strikethrough, plain URLs, www. addresses, and email addresses become tappable links without link syntax, and HTML comments are not shown. Raw HTML tags are displayed as text.

Notes, Tags, and Trash

  • Enter a title and body for a new note, then tap Save. Editor changes are written to local data only after you save.
  • The title and body share one section, the body area keeps a fixed height of about 17 lines, and the body uses a monospaced font for editing.
  • New tags in the tag picker are applied as draft state first and become persistent after the note is saved successfully.
  • Deleting a tag removes only the tag relationship; it does not delete associated notes.
  • Renaming a tag checks for empty names and normalized-name conflicts.
  • Tag colors are generated on device, so a tag keeps the same color in every list and in the editor without any extra setting.
  • Trash is a soft-delete area. Permanent deletion cannot be undone, so export important content first.

Import and Export

Full data

In the note list menu, choose Export Data to create a JSONL backup. Choose Import Data to restore a file.

  • A full backup contains notes, tags, and metadata, including notes in Trash.
  • Import is a merge and does not automatically delete local records that are missing from the backup.
  • Matching notes are handled by note ID and update time; tags are merged by normalized name or ID.
  • Imports are rejected when the file format or backup version is invalid.

Single note

For an existing note, use Export Note JSON or Import Note JSON in the editor. An imported note is loaded into the editor first; review it and tap Save when ready.

Frequently Asked Questions

Where is the search bar?

The search bar is hidden by default so it does not take up space in the list. Scroll to the very bottom of the list and pause for about one second, and it slides in above the bottom edge. It also stays visible while you type, while the search field is focused, and while more notes are loading. Because it is a floating overlay, it does not move the list content.

Why can I not find a note?

Check that you are not in Trash and that the search term and selected tag filter match the note title, body, or tag content. Clear the search field and selected tags, then try again.

Why does some Markdown not look the way I expected in Preview?

Check that the Markdown syntax is complete. For example, fenced code blocks need at least three backticks, tables need a header and separator row, and strikethrough needs ~~text~~ with no space directly after the opening tildes. Preview does not implement every extension supported by third-party Markdown editors, and raw HTML tags are shown as text.

How do I zoom or reset Preview?

Use the centered - and + buttons, pinch the content, or double-tap it. The reset button returns the view to 100%.

Can I recover a deleted note?

You can restore a note while it remains in Trash. After Delete Forever, the app does not provide an undo or restore action.

Does the app automatically back up or sync to the cloud?

The app does not provide automatic cloud sync, scheduled backups, or a server account. Device-level iOS backups and the file provider you choose are controlled by system settings.

Why did importing a backup not remove all local content?

Full data import is a merge operation. It does not clear local data before applying the backup, and local records missing from the backup are not automatically deleted.

Is it safe to share exported files?

Review the file first. JSON and JSONL backups may contain readable plain-text note content, so save and share them only in locations and with people you trust.

Still need help?

When contacting support, include the following information, but do not paste note content or a complete backup:

  • The app version, iOS version, and device model;
  • The feature involved, such as Preview, Import Data, or a tag action;
  • Steps that reproduce the problem;
  • An error message or screenshot that does not contain private content.

You can contact the developer at vegaodm@outlook.com. Please do not send a full backup or sensitive note content by email.
